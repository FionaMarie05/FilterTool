# FilterTool with Search and Group Selection

This tool allows users to load and analyze .lab or .txt files containing grouped data entries. It automatically organizes the data into main groups and subgroups based on naming conventions and displays them with selectable checkboxes. Users can easily search for specific groups, expand or collapse group details, and select or deselect groups for further processing. The tool also calculates and displays data transfer rates (bytes per second) for each group.

Key features include:

File loading with automatic data parsing and grouping
Search functionality to filter groups dynamically
Accordion-style interface with checkboxes for main groups and subgroups
Toggle buttons to expand/collapse group details
Buttons to select or deselect all groups at once
Export selected data entries to .lab or .txt files
Display of calculated data rates per group for better insight
